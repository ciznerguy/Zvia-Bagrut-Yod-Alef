## איך מריצים דוגמה

1. פותחים את הקובץ `Zvia-Bagrut-Yod-Alef.slnx` ב-Visual Studio.
2. ב-Solution Explorer לוחצים קליק ימני על הפרויקט של הפרקים הרצויים ובוחרים **Set as Startup Project**.
3. בקובץ `Program.cs` של אותו פרויקט, בפעולה `Main`, מוצאים את השורה של הדוגמה, למשל `// example25();`
4. מוחקים את שני הלוכסנים בתחילת השורה ומריצים.
